# Banda Reatância - Site Oficial

Site desenvolvido como projeto académico para a banda de rock "Reatância". A aplicação apresenta a história da banda, perfis dos membros, galeria de media, agenda de eventos e uma loja virtual. O layout foi estruturado para simular uma Single Page Application.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica, acessibilidade (foco visível, atributos alt) e otimização (loading="lazy").
* **CSS3:** Design responsivo adaptado para dispositivos móveis e desktop, com foco em usabilidade.
* **JavaScript:** Lógica de interatividade (modais, sistema de carrinho de compras, cálculos de totais).

## ⚙️ Pré-requisitos

Para executar e visualizar este projeto, precisas apenas de um navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari). Não é necessária a instalação de bibliotecas ou interpretadores adicionais.

## 🚀 Instruções de Execução

Como este projeto foi construído inteiramente com tecnologias front-end estáticas, a sua execução é direta. Podes utilizar um dos dois métodos abaixo:

### Método 1: Acesso direto no navegador (Mais simples)
1. Clona este repositório para o teu computador ou faz o download dos ficheiros em formato ZIP e extrai-os.
2. Abre a pasta extraída.
3. Clica duas vezes no ficheiro `index.html` para abri-lo diretamente no teu navegador padrão.

### Método 2: Acesso via Servidor Local (Recomendado para visualização técnica)
1. Abre a pasta do projeto no **Visual Studio Code**.
2. Certifica-te de que tens a extensão **Live Server** instalada.
3. Clica com o botão direito do rato no ficheiro `index.html` no explorador de ficheiros do VS Code.
4. Seleciona a opção **"Open with Live Server"**.
5. O site será aberto automaticamente no teu navegador num endereço local (ex: `http://127.0.0.1:5500`).
